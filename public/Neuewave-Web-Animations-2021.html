Neuewave Web Animations2021

Web assets and a generative colour wave for Neuewave’s identity.

DigitalNeuewave/MDRN

Scroll↓

Year
2021
Category
Digital
Techniques
p5.js, 3D web animation, generative graphics
Client
Neuewave/MDRN

Completed while with Neuewave.

Created digital web assets using p5.js for Neuewave’s identity. Created a landing page with 3D objects that rotate and move around their own axes, with the cursor providing a source of interaction, controlling the direction of the lights. Also made a generative colour-wave graphic for the identity, in which the waves keep changing and cycle at random through four primary colours.
