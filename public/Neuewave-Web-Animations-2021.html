Neuewave Web Animations2021

Web assets and a generative colour wave for Neuewave’s identity.

DigitalNeuewave

Scroll↓

Year
2021
Category
Digital
Techniques
p5.js, 3D web animation, generative graphics
Client
Neuewave

Completed while with Neuewave.

Worked on creating digital web assets using p5.js for Neuewave’s identity. Created a landing page with 3D objects that rotate and move around it’s own axis, with the cursor providing a source of interaction, controlling the direction of the lights. Also created a generative colour wave graphic for Neuewave’s identity where the waves are ever changing and cycling between the four primary colours randomly.
