Generative Type Tool2020

A browser tool for growing letterforms from 2D and 3D shapes.

Completed as part of the BA in Design Communication level 2 programme at LASALLE.

Try it out! Link here: Generative Type Tool

This type tool was created as part of a generative type workshop, to be able to explore the letterforms of type. Generating from a base shape, this tool allows the user to be able to manipulate the base shape, toggling between a set of 2D and 3D shapes, the scale, the speed of rotation, the degree of separation, text colour as well as background colour. Different camera axis also allows for different views to create endless posibilities of outcomes.
