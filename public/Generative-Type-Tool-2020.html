Open the tool: Generative Type Tool

This type tool was created as part of a generative type workshop, to explore letterforms. Generating from a base shape, the tool lets you change the base shape, toggling between a set of 2D and 3D shapes, the scale, the speed of rotation, the degree of separation, text colour as well as background colour. Different camera axes give different views, so the outcomes are endless.
