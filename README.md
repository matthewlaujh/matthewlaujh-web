# matthewlaujh.com

Static source for [matthewlaujh.com](https://matthewlaujh.com), migrated off Cargo (Cargo 2) to
Cloudflare Pages. `build.js` turns the page data in `src/` into plain HTML in `public/`.

## v3 — "Marquee"

- **Home** (`/`): the project list as a large serif title list (3/4) with the intro beside it (1/4),
  over a diffusion backdrop: a random project cover on load, slowly smeared through a curl-noise flow
  field; scrolling bleeds the next cover in. (`backdrops.js` `Diffuse`; the old slit-scan is still in
  the file, unused.) Hovering a title italicises it letter by letter and the project's cover
  follows the cursor; the slit-scan speeds up while you hover.
- **Project** (`/<slug>`): lands on a diffusion of the project's own cover, title + year, one-liner, category · school/client. Scroll:
  the text column (year, category, techniques, school/client, then the full text) and the plates
  on white. ← / → neighbours at the end.
- **All projects** (`/All-Projects`): every cover floating in space with mouse parallax; the list on
  the left pulls one forward; click grows it into the project page. Falls back to a 2-up grid on mobile.
- **About** (`/About`): on white.
- **Top bar on every page**: `← Matthew Lau` · the page title as a dropdown of all projects ·
  nothing on the right. **Footer**: studio clock (left) · `© year Matthew Lau` (right), blended
  so it reads on dark and on white.
- Per-project fields that Cargo didn't have live in each page JSON under `meta`:
  `line` (one-liner), `techniques`, `client_label` (School / Client / Studio / Exhibited at) and
  `client`. Drafted from the old text — edit freely.
- `backdrops.js` accepts `flip_y` in the slit-scan settings (photos need it; the tiled gradient didn't).

## Images

`src/img-original/` holds the untouched high-res files (local backup, git-ignored). `src/img/` is what
the site serves, generated by `python3 scripts/optimize-images.py` (needs Pillow + ffmpeg):
stills become WebP (≤2400px, q82) plus a `-s.webp` ≤1200px thumb for hover previews and the field;
GIFs become silent looping WebM + MP4 with a JPG poster. The script rewrites the `images` lists in
`src/pages/*.json`; `build.js` renders `<video>` for `.webm` entries. 192 MB → ~97 MB, and no
page loads a 13 MB GIF any more. Re-run after adding originals; existing outputs are skipped.

## Local preview

```
node build.js
node scripts/serve.js        # then open http://localhost:8000
```
The site uses clean URLs (`/Reconstructed-Colours-2026`, no `.html`) exactly as
Cloudflare Pages serves them, so a plain `python3 -m http.server` will 404 on
every link. `scripts/serve.js` resolves them the same way Cloudflare does.

```
src/
  site.json            title, description, homepage, nav order
  pages/<slug>.json    one file per page: title, content (Cargo HTML), local CSS, backdrop, images
  pinned/nav.json      the pinned-top "Nav" page (project list, desktop only)
  pinned/info.json     the pinned-bottom "Info" page (email, desktop only)
  lib/convert.js       Cargo grid/<br> markup -> semantic HTML (p, h2, ul, hr) + nav model
  css/site.css         the whole stylesheet: fonts, tokens, bar + dropdown, home, project, field, about, mobile
  js/site.js           dropdown, studio clock, lights-off, home cursor image, project reveal, field parallax
  js/backdrops.js      WebGL slit-scan backdrop + wallpaper slideshow, no dependencies
  fonts/               Austin News Deck + Atlas Grotesk (your own uploads from Cargo)
  img/                 images (see "Images" below)
  favicon.ico
build.js               src -> public
scripts/fetch-assets.sh  downloads all 129 images from Cargo's CDN into src/img
scripts/assets.json      CDN url -> local filename map used by that script
public/                generated output, what Cloudflare serves (committed so Pages needs no build)
```

## Build

```
node build.js            # regenerates public/
node scripts/serve.js    # clean-URL dev server on :8000
```

Each page becomes `public/<slug>.html`; Cloudflare Pages serves it at `/<slug>` (clean URLs), exactly
the URLs Cargo used. `/Front-Page` 301s to `/` (`public/_redirects`).

## Images (one-time step)

The 128 project images + GIFs (~120 MB; some GIFs are 10–17 MB, exactly what Cargo served) are
not in the repo yet. Fetch them once from Cargo's CDN, then rebuild:

```
./scripts/fetch-assets.sh
node build.js
```

Only `src/img/` needs the files; `build.js` copies them into `public/img/`. Run this before you
take the Cargo site down — the script reads from `freight.cargo.site`.

## Deploy to Cloudflare Pages

### Quick: direct upload from this folder (good for testing)

```
npx wrangler login                                              # once: opens the browser
npx wrangler pages project create matthewlaujh --production-branch main   # once
npm run deploy                                                  # builds, then uploads public/
```
Each deploy prints a `*.pages.dev` URL. The project name is set in `package.json`.

### Later: connect the repo so every push deploys

1. Push to GitHub/GitLab.
2. Cloudflare dashboard → Workers & Pages → Create → Pages → Connect to Git.
3. Build settings: Framework preset **None**, build command **`node build.js`** (or leave empty —
   `public/` is committed), build output directory **`public`**.
4. Add the custom domain `matthewlaujh.com`, then move DNS from Cargo to Cloudflare.

## v2 — changes from the Cargo baseline

- **Semantic markup**: Cargo's `<div grid-row><h1>…<br><br>…` is converted at build time into
  `<nav>`/`<main>`/`<article>` with real `<p>`, `<h2>`, `<ul>`, `<hr>`. The nav is generated from
  `src/pinned/nav.json` once (Cargo rendered it twice on the home page, on top of itself).
- **Type**: tokenised 1.2-ratio scale (`--fs-meta .85 · small 1 · body 1.2 · label 1.45 rem`),
  line-height 1.3, paragraph gap 0.55em, `text-wrap: pretty` with a JS widow fallback.
  The rem base still follows Cargo's viewport formula, so sizes track the old site.
- **Colour / states**: tokens in `:root`; hover underline on links, focus outlines, rules at 34%.
- **Slit-scan backdrop**: time-based motion (Cargo advanced per frame → 2× speed on 120 Hz);
  the `dimensions` uniform now uses the value Pixi actually rendered with (the canvas pixel size),
  which restores the multi-band look; scroll coupling eased with inertia; pauses off-screen,
  under `prefers-reduced-motion`, and when the tab is hidden; `?tune` opens live sliders that print
  settings to paste into the page JSON.
- **Wallpaper**: no autoplay under reduced motion; overlay colour is a CSS token.
- **Studio clock** in the footer (Mon–Fri 09:00–19:00 Asia/Singapore) with a clockwise-filling dot.
- **Lights-off** outside those hours: darker palette, backdrop dimmed and slowed (0.35×); the
  first click / key / scroll / tap turns the lights on for the session. `?lights=off|on` to test.
- **Mobile**: ☰ toggles (and closes) the full-screen menu, which now carries the nav, the intro
  and the footer.
- **Dropped**: Cargo's engine CSS, grid attributes, `data-css-preset` scaffolding, dead nav links
  rendered as plain text.

## What was ported, and how

- **Typography & layout**: Cargo's base unit — `html { font-size: N% }` computed from the viewport
  (`min(w,h) × weight / 100`, weight 9 → 19 as the window gets taller than wide, mobile_zoom 25) —
  is reproduced in `site.js`, so every `rem` lands on the same pixel size as on Cargo.
- **Grid**: Cargo's `[grid-row] / [grid-col] / [grid-pad] / [grid-gutter]` system comes from
  `cargo-base.css` unchanged; `body.mobile [grid-responsive] [grid-col]` stacks columns under 770px.
- **Pinned Nav / Info**: fixed overlays on desktop, removed on mobile (Cargo's `exclude_mobile`).
  On mobile the ☰ button opens the Front Page as a full-screen menu, as Cargo did.
- **Slit-scan backdrop** (Front Page, About, mobile menu): same shader and motion code as Cargo's
  PIXI plugin, re-implemented in raw WebGL. Settings live in each page JSON under `backdrop.settings`
  (vertical, 8 scan cycles, wiggle 10, speed 50, mouse + scroll interaction).
- **Wallpaper backdrop** (every project page): fading slideshow of the page's images, "contain"
  scaling inside a 12.5%-of-the-short-side margin, white background under a 50% black overlay,
  10 s per slide, 0.5 s cross-fade, hover-to-reveal arrows. Settings in each page JSON.
- **Current-page link** in the nav is bold (`.page a.active`), as on Cargo.
- **Dead link kept as-is**: "Affective Communication Research (2021-2022)" in the nav pointed to
  a page that 404s on Cargo too. Create `src/pages/Affective-Communication-Research-2021-2022-Ongoing-Project.json`
  if you want it to resolve.
- **Not ported**: Cargo's in-page (AJAX) navigation — links are normal page loads now; Cargo's
  proprietary icon font (the ☰ is an inline SVG); the iA Writer Quattro face that only the unused
  thumbnail/caption styles referenced.

## Editing content

Edit the `content` HTML in a page JSON (it is the HTML Cargo stored), or add a new page JSON with
`slug`, `title`, `content`, `images`, `backdrop`, then `node build.js`. Add a link to it in
`src/pinned/nav.json` and `src/pages/Front-Page.json`.
